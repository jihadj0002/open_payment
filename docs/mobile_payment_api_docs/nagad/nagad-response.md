# NagadResponse

The `NagadResponse` class represents the response received after a Nagad payment transaction.

## Class Definition

```dart
class NagadResponse {
  String? merchantId;
  String? orderId;
  String? paymentRefId;
  String? amount;
  String? clientMobileNo;
  String? merchantMobileNo;
  String? orderDateTime;
  String? issuerPaymentDateTime;
  String? issuerPaymentRefNo;
  String? additionalMerchantInfo;
  String? status;
  String? statusCode;
  String? cancelIssuerDateTime;
  String? cancelIssuerRefNo;
  String? serviceType;
}
```

## Response Fields

| Field | Type | Description |
|-------|------|-------------|
| `merchantId` | `String?` | Unique merchant identifier |
| `orderId` | `String?` | Unique order identifier (generated by merchant) |
| `paymentRefId` | `String?` | Nagad payment reference ID |
| `amount` | `String?` | Transaction amount |
| `clientMobileNo` | `String?` | Customer's mobile number |
| `merchantMobileNo` | `String?` | Merchant's mobile number |
| `orderDateTime` | `String?` | Date and time of order creation |
| `issuerPaymentDateTime` | `String?` | Date and time of payment by issuer |
| `issuerPaymentRefNo` | `String?` | Issuer payment reference number |
| `additionalMerchantInfo` | `String?` | Additional merchant info passed during payment |
| `status` | `String?` | Transaction status |
| `statusCode` | `String?` | Transaction status code |
| `cancelIssuerDateTime` | `String?` | Date and time of cancellation (if cancelled) |
| `cancelIssuerRefNo` | `String?` | Cancellation reference number |
| `serviceType` | `String?` | Type of service used |

## JSON Serialization

### From JSON

```dart
NagadResponse response = NagadResponse.fromJson(jsonMap);
```

### To JSON

```dart
Map<String, dynamic> json = response.toJson();
```

## Status Codes

| Status | Description |
|--------|-------------|
| `Success` | Payment completed successfully |
| `Cancel` | Payment was cancelled by the customer |
| `Pending` | Payment is being processed |

> **Note:** Always store the required details in your database for future reference and reconciliation.
