## Decisions Made
- Used modular monolith pattern (not microservices) for simplicity at this stage
- Chi router over gin/fiber for idiomatic Go + excellent middleware support
- pgx v5 over database/sql for native Postgres features and better performance
- Mock processor as a separate Go binary for realistic integration testing
- Separate `web/go.mod` to avoid Go tooling scanning node_modules
- Interfaces introduced in payment + merchant services to enable mocking in tests
